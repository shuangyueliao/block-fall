# Block Fall

Free single-file HTML5 falling-block puzzle game. Stack the seven classic
tetromino shapes, fill complete rows to clear them, and chase higher levels
as the stack speeds up. One HTML file, zero external assets.

**Play:** https://shuangyueliao.github.io/block-fall/

- Keyboard: ←/→ move, ↑ rotate, ↓ soft drop, Space hard drop, P pause
- Mobile: five on-screen touch buttons (move / rotate / soft drop / hard drop)
- 7-bag randomizer, simple wall kicks, ghost piece, next-piece preview
- Line-clear scoring (100/300/500/800 × level), level up every 10 lines
- Procedural canvas graphics and WebAudio sounds, best score saved locally
